Observe.

Capture identity, network, shard, readiness, height, and the exact finalized-block payload before making a stronger claim.

02

Fingerprint.

Hash the observed payload so later analysis refers to exact bytes, not a remembered interpretation.

03

Cross-check.

Compare configured nodes and canonical block representations. Agreement is evidence; disagreement is a lead.

04

Interrogate conflict.

A hash mismatch or missing evidence fractures the trace at the first unsupported edge instead of being averaged away.

05

Explain.

Turn raw checks into a human-readable chain: why this block, which evidence, which source, which boundary.

06

Verdict.

PASS / WARN / FAIL describes the observed evidence package—not omniscient truth and not independent Casper finality.

    FINALITY BOUNDARY

    RNode reports finality; canonical and cross-node observations corroborate the block. This showcase does not establish independent stake-weighted Casper finality.

    02 / EVIDENCE MATRIX

    04 / CLAIM BOUNDARY

    Evidence can narrow a claim. It cannot manufacture authority.

    OBSERVED

    RNode assertion

    The node can report a block finalized. Sentinel records that assertion and its source.

    CORROBORATED

    Canonical + cross-node

    Representations and configured observations can agree on identity and height.

    INVENTORIED

    Casper-shaped evidence

    Bonds, stake, validators, justifications and protocol fields can be inspected structurally.

    NOT PROMOTED

    Independent Casper finality

    Without authenticated validator identities, stake-weighted propositions, signatures and exact protocol verification, this remains outside the current claim.
